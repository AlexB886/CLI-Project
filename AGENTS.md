# AGENTS.md

`tareas` — CLI para automatizar tareas repetitivas con ficheros (Typer, Python ≥3.12). Src layout: único paquete en `src/tareas/`, build backend `uv_build`.

## Toolchain: uv, nothing else
- Use `uv sync` / `uv add` / `uv run <cmd>`. Never `pip` or manual venv; `.venv/` is disposable and regenerated by `uv sync`.
- Python is pinned to 3.12 via `.python-version`.
- Run the CLI: `uv run tareas --help`.

## Gotchas
- `pyproject.toml` declares the entrypoint `tareas = "tareas.cli:app"`, but `src/tareas/cli.py` does NOT exist yet — every `uv run tareas ...` fails with `ModuleNotFoundError: No module named 'tareas.cli'` until a Typer `app` is created there.
- No tests, linter, formatter, or CI configured yet. `opencode.json` pre-allows `uv run pytest *`; if adding tests, use pytest via `uv add --dev pytest`.

## Conventions
- User-facing text (docstrings, CLI `--help`, comments) is in Spanish; match that style.
- Secrets live in `.env`, never committed. Repo config (opencode.json) denies reading `.env*` and denies `git push` / `rm` / `sudo`; edits require permission.
